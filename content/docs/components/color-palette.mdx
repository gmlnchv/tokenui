## Overview

**ColorPalette** displays labeled color collections as horizontal or vertical strips—perfect for documenting color ramps, scales, brand palettes, and semantic token sets.

These layouts are intentionally flexible and easy to reshape. You get a pre-composed `ColorPalette` for speed, plus primitives (`ColorSwatch`, `ColorSwatchLabel`, `ColorPaletteLabel`) to build custom layouts like grids or asymmetric compositions.

## Usage

The default `ColorPalette` component is the fastest way to render a collection of colors with automatic labels and hover states.

<Preview code={`import { ColorPalette } from '@/registry/components/color-palette'

<div className="space-y-4">
  <ColorPalette 
    label="Indigo"
    colors={['#e0e7ff', '#c7d2fe', '#a5b4fc', '#818cf8', '#6366f1', '#4f46e5', '#4338ca', '#3730a3', '#312e81']} 
  />
</div>`}>
  <div className="space-y-4">
    <ColorPalette 
      label="Indigo"
      colors={['#e0e7ff', '#c7d2fe', '#a5b4fc', '#818cf8', '#6366f1', '#4f46e5', '#4338ca', '#3730a3', '#312e81']} 
    />
  </div>
</Preview>

### Customize swatches

<Preview code={`import { 
  ColorSwatch, 
  ColorSwatchPart, 
  ColorPaletteLabel 
} from '@/registry/components/color-palette'
import { ColorContrast, ColorContrastBadge } from '@/registry/components/color-contrast'

<div className="space-y-2">
  <ColorPaletteLabel>Brand Ramp (with Scores)</ColorPaletteLabel>
  <div className="flex h-20 overflow-hidden rounded-md border text-white">
    {['#f0f9ff', '#0ea5e9', '#0369a1', '#075985'].map((h) => (
      <ColorSwatch key={h} value={h} className="group flex-1">
        <ColorSwatchPart position="top-left">
          <ColorContrast against="#ffffff">
            <ColorContrastBadge className="opacity-70 group-hover:opacity-100" />
          </ColorContrast>
        </ColorSwatchPart>
      </ColorSwatch>
    ))}
  </div>
</div>`}>
  <div className="space-y-2">
    <ColorPaletteLabel>Brand Ramp (with Scores)</ColorPaletteLabel>
    <div className="flex h-20 overflow-hidden rounded-md border text-white">
      {['#f0f9ff', '#0ea5e9', '#0369a1', '#075985'].map((h) => (
        <ColorSwatch key={h} value={h} className="group flex-1">
          <ColorSwatchPart position="top-left">
            <ColorContrast against="#ffffff">
              <ColorContrastBadge className="opacity-70 group-hover:opacity-100" />
            </ColorContrast>
          </ColorSwatchPart>
        </ColorSwatch>
      ))}
    </div>
  </div>
</Preview>

### Vertical layout

Toggle the layout with `orientation="vertical"` for tight sidebars or detailed token lists:

<Preview code={`import { ColorPalette } from '@/registry/components/color-palette'

<div className="grid grid-cols-3 gap-4">
  <ColorPalette

  <ColorPalette

## API Reference

### ColorPalette

Pre-composed palette component with labels shown by default.

<AutoTypeTable
  name="ColorPaletteProps"
  type={`
export type ColorPaletteProps = {
  /** Array of colors to display */
  colors: string[] | ColorStop[]
  /** Orientation of the palette (default: horizontal) */
  orientation?: 'horizontal' | 'vertical'
  /** Optional label */
  label?: string
  /** Additional class name for the wrapper (label + palette stack) */
  className?: string
}
`}
/>

### ColorSwatch

A single color swatch in a palette.

<AutoTypeTable
  name="ColorSwatchProps"
  type={`
export type ColorSwatchProps = {
  /** Color value (hex, rgb, hsl, etc.) */

  /** Optional name/label for the color */

}
`}
/>

### ColorSwatchLabel

Label displayed on hover inside a color swatch.

### ColorPaletteLabel

Label displayed above a palette.
